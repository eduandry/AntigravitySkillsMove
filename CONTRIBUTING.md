# Contributing to AntigravitySkillsMove

Thank you for your interest in improving **AntigravitySkillsMove**! We welcome contributions from developers, technical writers, and AI practitioners.

---

## 🛠️ How to Contribute

1. **Fork the Repository** on GitHub.
2. **Clone your fork**:
   ```bash
   git clone https://github.com/eduandry/AntigravitySkillsMove.git
   cd AntigravitySkillsMove
   ```
3. **Create a feature branch**:
   ```bash
   git checkout -b feature/amazing-new-feature
   ```
4. **Make your changes** (ensure code adheres to PEP 8 standards and is cross-platform).
5. **Test locally**:
   ```bash
   python antigravity_skills_move.py --list
   ```
6. **Commit with clear messages**:
   ```bash
   git commit -m "feat: add automatic cloud encryption to bundles"
   ```
7. **Push to your branch and open a Pull Request**.
